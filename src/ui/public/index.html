      Hướng dẫn

      Task mớiTính năng chưa có, từ file spec. Kết thúc bằng E2E.
      CloneBê tính năng đã có từ repo mẫu. Không cần spec.

      Task mới và Clone ghi vào dự án nên mỗi lúc chạy một. Tối ưu SQL chạy song song được.

      Task mới

      1. Đọc dự án — index + quy ước, lưu cho lần sau.
      2. Thiết kế — spec thiếu quyết định nghiệp vụ thì dừng hỏi (Chờ trả lời).
      3. Duyệt thiết kế — AI khác review, 1 vòng mỗi lần chạy.
      4. Chia việc → Viết code — build check sau mỗi task; lỗi thì dừng.
      5. E2E — Playwright theo tiêu chí nghiệm thu.
      # Tên tính năng
## Bối cảnh
## Yêu cầu
## Ràng buộc
## Tiêu chí nghiệm thu
- [ ] Bấm X thì thấy Y.
      • Tiêu chí phải kiểm được trên giao diện.
      • Chờ trả lời: điền Tuỳ chọn → Trả lời câu hỏi nghiệp vụ, chạy lại cùng spec.
      • DB: chuỗi kết nối + thư mục SQL; script mới chạy sau mỗi task, lệnh xoá dữ liệu bị chặn.

      Clone

      Truy tìm → đọc dự án đích → bảng ánh xạ → port → kiểm phủ, nối FE↔BE → build → unit test. Đọc bảng ánh xạ trong báo cáo.

      Tối ưu SQL

      • AI đề xuất từng bước; AI khác kiểm độc lập; bước không chắc giữ nguyên kết quả bị loại.
      • Logic nghiệp vụ giữ nguyên trừ khi ghi ở Đổi logic nghiệp vụ.
      • DB thử nghiệm: mỗi bước chạy thật rồi rollback; chỉ giữ bước cho đúng kết quả và không chậm hơn. Không dùng production.

      Chạy lại cùng thiết lập là tiếp từ chỗ dừng. Đóng trình duyệt không dừng lần chạy.

      An toàn

      • Chỉ mở ở 127.0.0.1, không đăng nhập. Không đưa ra mạng.
      • AI được chạy lệnh shell trong dự án đích.
      • Không dán văn bản không tin cậy vào spec.
